# Domain Docs

This repository uses a single-context domain model.

Before exploring or changing a domain area, read:

- `CONTEXT.md` at the repository root.
- Relevant records in `docs/adr/`.

Use the glossary vocabulary from `CONTEXT.md` in issue titles, plans, tests, and implementation notes. If a change conflicts with an ADR, call out the conflict explicitly rather than silently overriding it.
